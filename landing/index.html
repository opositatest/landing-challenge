Que tienes que construir

Construye la landing con una arquitectura clara de componentes y documenta en Storybook lo necesario para que otra persona pueda reutilizarlos.

  • Usar Lit para construir componentes reutilizables.
  • Montar la landing desde la web externa, no desde un componente contenedor dentro de la libreria.
  • Documentar en Storybook los componentes.
  • Trabajar a partir de la referencia visual de Figma.

Se valorara especialmente

Lo mas importante no es hacer mas componentes, sino tomar buenas decisiones de sistema.

  • Jerarquía de componentes bien pensada: atomos, moleculas, organismos o una estructura equivalente coherente.
  • Reutilización real, naming claro y una API consistente.
  • Estados, variantes, accesibilidad básica y uso de CSS variables.
  • Calidad visual general.
